Як влаштована та як запускається база даних AirL

База даних сайту побудована за архітектурою Embedded JSON Document Database. Вона не вимагає встановлення сторонніх громіздких СУБД (PostgreSQL / MySQL / MongoDB) та працює автоматично при старті бекенду.

1. Як запустити базу даних:

База даних запускається разом із бекенд-сервером:

  • Спосіб 1 (Швидкий запуск): Двічі клацніть файл start-server.bat у корені проєкту. Сервер та база даних активуються на порту 3000.
  • Спосіб 2 (Через термінал): Виконайте команду agy-node server.js (або node server.js).
  • Спосіб 3 (Native PowerShell): Запустіть powershell -File server.ps1.

2. Де зберігаються дані:

Усі таблиці зберігаються у папці data/:

  • data/orders.json — усі оформлені замовлення, кошики, обрані кольори та суми.
  • data/subscribers.json — база email-адрес підписників клубу.
  • data/tickets.json — звернення до служби підтримки та консьєрж-сервісу.
  • data/products.json — каталог моделей дронів, ціни та кількість на складі.

3. Як редагувати або створити резервну копію:

Ви можете в будь-який момент відкрити будь-який файл із папки data/ у Блокноті або VS Code, відредагувати ціну чи кількість, або просто скопіювати папку data/ на флешку для бекапу.
